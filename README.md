# Restaurant Website
A responsive and interactive restaurant website developed using **HTML, CSS, and JavaScript**. The website provides a complete online dining experience where users can explore food items, add items to their cart, place orders, and make payments.

## Features
* 🍽️ Browse and explore food items
* 🛒 Add food items to the cart
* 💳 Online payment option
* 📅 Table/restaurant booking facility
* 👨‍🍳 About Our Chef section with chef details
* 📖 About Us page
* 📞 Contact Us section
* 🧾 Order and cart management
* 📱 Responsive and user-friendly interface

## Technologies Used
* **HTML** – Website structure
* **CSS** – Styling, layout, and responsive design
* **JavaScript** – Interactivity, cart functionality, booking, and payment-related features

This project was created to provide users with a convenient and interactive platform for exploring a restaurant's menu, booking a table, purchasing food items, and making payments online.
